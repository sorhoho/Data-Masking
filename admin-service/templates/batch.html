📄 Batch File Masking

Upload & Mask File

Upload a CSV, JSON, or Parquet file. Each row is masked according to the selected role's policy. The masked file is returned as a download.

Supported: CSV, JSON, Parquet
API — POST /api/mask/batch

Accepts JSON, returns masked records. Requires X-Api-Key header. 

POST /api/mask/batch
X-Api-Key: <governance-internal-key>
Content-Type: application/json

{
  "role": "agent",
  "customer_id_field": "customer_id",
  "records": [
    {
      "customer_id": "C001",
      "name": "Alice Smith",
      "email": "alice@example.com",
      "msisdn": "+60123456789",
      "national_id": "850101-01-1234",
      "address": "123 Main St, KL"
    }
  ]
}

→ 200 OK
{
  "masked_records": [...],
  "denied": 0,
  "policy_version": 3
}
Expected fields
  • customer_id — looked up in OPA for tier/access
  • name, email, msisdn
  • national_id, address
  • last_call_duration, data_roaming_gb, last_location
Related Services
  • Kafka — consume raw.customer.events, publish to masked.customer.<role> via kafka-masker service
  • Data Lake — export Parquet to MinIO via DW Masker ↗
  • Data Warehouse — refresh masked PostgreSQL views at POST http://localhost:5003/views/refresh
  • Data Mart — build mart schemas at POST http://localhost:5003/marts/build
